Day 2 prototype of the Electronic Monitoring Order form

This prototype builds on what has been built to date by the development team. It includes improvements to:

  • bring us more inline with GDS patterns
  • content enhancements
  • enhance the journey for the different types of users using the outputs from the page review workshop on the 3 December
  • add variation journeys based on the findings from the discovery user research in December
  • include improvements from the variations prototype UR in January
  • new questions to determine the order type description

View the EMO prototype change log to see current and outstanding issues the service needs to solve.

Key journeys:

  • Create and send a new order form
  • Postcode lookup component
  • Digital prison services page

Error pages:

  • Form submit critical failure
  • Form submit non critical failure
  • Access denied
  • 404 page not found
  • 500 there was a problem with the service
  • 503 shutter page (planned outage)

UR journeys:

  • New offence list (using the list from DPS)
  • New OTD list
  • Old OTD list (with conditional logic)
  • Whole journey with error on submission for UR

  • Search
  • Alternative search design
